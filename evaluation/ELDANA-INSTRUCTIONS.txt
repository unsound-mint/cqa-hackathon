Эльдана, привет!

1. Сохрани «Разметка.html» на ноутбук. Открой двойным щелчком в Chrome или Edge. Установка, GitHub и интернет не нужны. Работай в обычном окне, не инкогнито.
2. Вверху выбери своё имя в списке «Рецензент». Для другого человека нажми «Новый рецензент» и введи его имя. Каждый начинает с пустых ответов; ответы, прогресс и история раздельные. Чтобы продолжить свою работу, выбери своё имя. Выбирай диалог слева; фильтры позволяют выбрать RU/KZ/EN, чат/звонок и незавершённые диалоги.
3. Сначала прочитай весь диалог. Оценивай только оператора. У каждого критерия есть «Правило оценки»; основной источник — PDF организаторов, который Денис пришлёт вместе с файлом.
4. Выбирай ответ, затем нажимай на сообщения для доказательств. Номер сообщения начинается с 0. Для отсутствующего действия укажи просмотренный диапазон, например 0-12. Кратко объясни решение; сомнения отметь в списке под причиной. Н/Д — только по условию критерия, а не вместо сомнения.
5. Начни примерно с 10 разных диалогов (разные языки, чаты и звонки), затем обсуди спорные места с Денисом. После согласования правил продолжи до 20–25. Ничего не подгоняй под модель — её оценок здесь нет.
6. Ответы сохраняются автоматически в этом браузере на этом ноутбуке. После каждой сессии нажми «Скачать CSV» и «Скачать резервную копию». Дождись двух файлов и отправь оба Денису личным сообщением. Можно отправлять частично заполненную разметку.
7. CSV нужен для сравнения; JSON-копия содержит ответы и историю изменений. На другом ноутбуке открой тот же HTML и выбери JSON через «Восстановить копию». Восстановление разрешено только в пустую разметку выбранного рецензента, чтобы случайно не затереть работу. Если уже есть ответы, скачай их копию и попроси Дениса помочь.
8. Не переименовывай и не перемещай HTML в середине работы: браузер может перестать видеть сохранения. Если ответы исчезли, восстанови последнюю JSON-копию. Не очищай данные браузера до передачи файлов.

Файл содержит приватные диалоги. Не выкладывай HTML, CSV или JSON публично. Аудио открывается отдельной ссылкой и может требовать интернет; по одному тексту не оценивай тон и дикцию.

Другие участники могут открыть тот же HTML на своих ноутбуках — каждый размечает независимо. Каждый отправляет свои CSV и JSON с именем в названии. Не объединяйте CSV вручную: сравнение разных оценок делает Денис.
